01 · Overview

ACE.to.DDS.converter.for.MSTS

Microsoft Train Simulator stores textures in the legacy .ace format. Modern tooling, and Open Rails, increasingly prefer .dds. This converter batches a folder of ACE textures into DDS. No per-file fiddling.

The tool is one .7z archive. Extract it anywhere and run it. No installer. No registry entries. Nothing left behind.

  • Batch ACE to DDS. Point it at a folder and convert the set.
  • MSTS ready. It understands ACE textures used by routes and consists.
  • Open Rails compatible. The DDS files load in OR sessions.
  • Portable. Extract and run from any folder or USB stick.

Keep a backup of the original .ace files. You may want a route back on the originals later.

  • Windows 10 or Windows 11, 64-bit.
