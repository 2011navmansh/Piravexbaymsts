The stock MSTS Activity Editor is the old way to build a run. You pick the route, choose the player locomotive and consist, draw the path the player will follow, then drop in AI services so other trains move on the same timetable. Save it into the route's Activities folder and it shows up in Microsoft Train Simulator and Open Rails.

This page plays the commentary guide: How to create activity in MSTS Tutorial · Commentary · MSTS Open Rails. Follow the folder names it shows. A missing path or a consist that is not installed is the usual reason an activity refuses to start.

What you will learn

  • How to open the old MSTS Activity Editor
  • How to pick a route, start time and player service
  • How to set the player path and station stops
  • How to add AI traffic so other trains run beside you
  • How to save the activity and test it in MSTS and Open Rails

Requirements

  • Microsoft Train Simulator with the stock Activity Editor, or Open Rails to test the saved activity
  • A route already installed, plus the consist you want to drive
  • The commentary video on this page

If the activity will not load, check that the consist still exists in TRAINS\CONSISTS\ and the path file is in that route's Paths folder. Support, if you want it, is on the MSTS donation page. The guide stays free.
