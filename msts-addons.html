Install

Four steps. Routes, locos, sounds, mods.

01

Download and extract

Download the zip or rar and extract it with WinRAR or 7-Zip.

02

Copy to the right folder

Routes go to ROUTES\, locos to TRAINS\TRAINSET\, sounds to SOUNDS\.

03

Run installme.bat

If the pack ships installme.bat, run it to pull the required default assets.

04

Launch and run

Open MSTS or Open Rails, select the new content, and start the session.
