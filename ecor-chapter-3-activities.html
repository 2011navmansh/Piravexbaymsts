The coast

Kharagpur to Brahmapur.

These eleven files are built for The East Coast Railway MSTS – Chapter 3. The set covers the Odisha coastal mainline: Kharagpur, Bhadrak, Cuttack, Bhubaneswar, Khurda Road, Puri and the Chilika Lake run toward Brahmapur.

  • Requires the ECOR Chapter 3 route. Each activity loads from that route's ACTIVITIES folder.
  • Install the track packs listed on the route page before you run an activity.
  • Works with Microsoft Train Simulator and Open Rails on Windows.
Load

Four steps. Then drive.

01

Download the file

Choose the activity and save the archive.

02

Extract

Right-click the RAR or 7Z and extract with WinRAR or 7-Zip.

03

Copy to the route

Move the files into the ACTIVITIES folder of ECOR Chapter 3 in .../Train Simulator/ROUTES/.

04

Drive

Open MSTS or Open Rails, select the activity, and start the run.
