In the release

  • Common protocols — HTTP, FTP, BitTorrent, magnet and Metalink in one app.
  • Built on aria2 — the proven multi-protocol download engine, tuned for speed.
  • Task control — pause, resume, retry and prioritize every download.
  • Local first — no account required. Everything stays on your machine.
  • Browser handoff — send links from the official Chrome, Edge, Firefox and Safari extensions.
  • Plugins — add naming rules, link resolution and more, only what you need.
  • Desktop and server — Windows, macOS and Linux apps, plus Docker for NAS and home servers.
  • Open source since 2018 — 57.9K GitHub stars, 23.2M release downloads, 5.1K forks and 64 releases.

Free and open source under the MIT licence. Distributed from the official motrix.app and GitHub releases. Beta builds are also listed on the official download page. “A no-nonsense download manager that provides a clean look out of the box.” — It's FOSS.

Install

Pick a build. Run it.

01

Download the build

Windows .exe or .zip, macOS .dmg or .zip, Linux AppImage, deb, rpm, pacman or flatpak, or the fnOS package.

02

Install or run

Run the installer, unpack the ZIP, open the DMG, or run the AppImage. On fnOS, upload the FPK in App Center.

03

Add the extension

Install the official browser extension so links are handed off to Motrix.

Paste a link, add a magnet or torrent, or let the extension catch it.
