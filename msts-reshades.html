Install

Four steps. Then press Home.

01

Install ReShade

Run the ReShade installer and point it at train.exe or OpenRails.exe.

02

Download and extract

Grab the RAR and extract it with WinRAR or 7-Zip.

03

Copy the preset

Drop the .ini into the folder where ReShade was installed, next to the game exe.

04

Load and drive

Launch MSTS or Open Rails, press Home, pick the preset, and start driving.

These are preset archives, not the ReShade installer. Install ReShade first, then load one .ini at a time so you can tell which look you are running.
