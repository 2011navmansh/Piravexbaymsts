Mister Download Manager.

Downloads faster than IDM. Free, forever. An open-source, clean-room download manager written from scratch in pure Rust — up to 32 connections per file, crash-safe resume, torrents, videos, galleries and 86 languages. No ads, no trial, no account.

Windows x64 Installer · 16.3 MB · v0.5.2

Files, torrents and videos. One window.

MDM splits a file into up to 32 parts, re-splits the slowest one until the last byte, and resumes after a crash or a dropped connection. The installer registers the browser helper and asks your language on first start. Updated 9 Nov 2026.

In the release

  • 32 connections per file — adaptive segmentation that keeps re-balancing until the last byte. MDM's own benchmark finishes a 1 GB file in 1 second against IDM's 5.5 seconds.
  • Crash-safe resume — a restart, a crash or a dropped connection never starts the file over.
  • HTTP, HTTPS, FTP and FTPS — explicit and implicit TLS, proxies, SOCKS and proxy auto-config (PAC) scripts.
  • Browser handoff — Chrome, Edge, Brave, Opera, Vivaldi, Firefox, Zen, Helium, LibreWolf, Floorp and Waterfox. Safari gets an extension inside the Mac app.
  • Videos and galleries — yt-dlp and ffmpeg bring playlists, channels, subtitles, audio-only files and signed-in videos; gallery-dl takes whole image galleries.
  • Torrents — magnet links, .torrent files, sequential download, RSS feeds, seeding limits, file selection, peers and share ratio through librqbit.
  • Scheduler and queues — start and stop overnight, wake the computer, then shut it down when the queue ends.
  • Remote and headless — manage downloads from a phone on your network, or run MDM with no window on a NAS, Docker or Unraid.
  • Free and open source — GPL-3.0, 86 languages, 9 themes, no ads, no trial and no account.

Free and open source under the GPL-3.0 licence. MDM is an independent, clean-room program: it contains no code, binaries or assets from Internet Download Manager. Source, releases, help pages and the issue tracker live on GitHub; the official site is misterdownloadmanager.com. 4.4K stars · 310 forks · 8 releases.

Sizes are the official GitHub release sizes for v0.5.2. The setup file is the easiest choice on Windows: it installs MDM, connects it to your browser and asks your language. The portable ZIP keeps everything in its own folder, for a USB stick. On Linux, sudo apt install ./<file>.deb or sudo dnf install ./<file>.rpm; make the AppImage executable and run it. On a Mac, open the DMG, drag MDM to Applications, then right-click the app and choose Open the first time.

Features

Everything a download manager should do.

01

32 connections

Fetch many parts at once and re-split the slowest until the last byte.

02

Crash-safe resume

Restart, crash or dropped connection — it picks up where it left off.

03

All the protocols

HTTP, HTTPS, FTP and FTPS, with proxies, SOCKS and PAC scripts.

04

Browser handoff

Chrome, Edge, Brave, Opera, Vivaldi, Firefox and its forks; Safari on Mac.

05

Video downloads

Playlists, channels, subtitles, audio-only files and signed-in videos.

06

Image galleries

Whole galleries from Flickr, Imgur, DeviantArt and more with gallery-dl.

07

Torrent client

Magnet and .torrent, sequential order, RSS feeds, seeding limits, peers and ratio.

08

Link grabber

Sort many links into packages, then extract ZIP, 7z and RAR archives.

09

Debrid accounts

Real-Debrid, AllDebrid and Premiumize through their official APIs (experimental).

10

Scheduler

Queues that start and stop on their own, wake the PC and shut it down after.

11

VPN binding

Hold every download to one network adapter, with a kill switch and encrypted DNS.

12

Remote & headless

Control from your phone, or run windowless on a NAS, Docker or Unraid.

13

CLI, API & MCP

IDM-style command-line switches, a local API, and an MCP server for AI assistants.

14

Speed limiter

Limit one download or all of them, only while you're at the computer.

15

Themes & size

9 built-in looks, your own TOML or JSON theme, and interface size up to 200%.

16

86 languages

Every language Windows 11 offers, with right-to-left layouts for Arabic and more.

17

Keyboard & screen readers

Every window and dialog works from the keyboard and reads with Narrator or NVDA.

18

Portable & updates

A USB-stick build, signed automatic updates, crash reports and logs.

19

5× faster

1 GB: 1 second against IDM's 5.5. A small file: instantly against 3.1 seconds.

20

Free & open source

GPL-3.0, no ads, no trial, no sign-up. Free forever.

Benchmark

Same files. Same PC. Less waiting.

Both programs downloaded the same files from the same local test server, seven runs each, both at default settings. MDM finished first in all seven scenarios; every difference is statistically significant (Mann-Whitney p < 0.001), and MDM used less CPU in every one. Install

Pick a build. Run it.

01

Pick a build

Setup .exe if you're not sure, portable ZIP for a USB stick, or the AppImage, DEB, RPM or tar.gz on Linux. Mac builds are experimental.

02

Install or unpack

Run the installer, unzip the portable folder, install the package, make the AppImage executable, or drag the Mac app to Applications.

03

Connect the browser

The setup file registers the native host. Add the extension from the Chrome Web Store or Firefox Add-ons to catch links and videos.

04

Start a download

Paste a link, copy a file link, add a torrent or magnet, or let the extension hand it over.
