Install

Four steps. Then listen.

01

Download and extract

Grab the ZIP or RAR and extract it with WinRAR or 7-Zip.

02

Run installme.bat

Double-click installme.bat so the .s files copy into \SOUNDS\ and the default assets come with them.

03

Match the names

The loco .eng file has to use the exact sound names listed in the pack README.

04

Launch and listen

Open MSTS or Open Rails and test horn, brake and engine sounds from the cab.

These are sound archives, not a new simulator install. Keep the extracted names unchanged so the .eng file can find them.
