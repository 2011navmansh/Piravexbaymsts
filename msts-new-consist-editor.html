piravexbay MSTS / consist editor

The MSTS New Consist Editor is a lightweight Windows tool that builds and edits train consists for Microsoft Train Simulator and Open Rails without hand-editing .con files. Pick a locomotive, add coaches or wagons, drag them into order, set the numbers, and save. The editor writes a clean consist that both sims can load straight away.

It reads the trainsets already installed in your MSTS folder, so every loco, coach and wagon you own shows up in the list. A single WAP-7 with 24 coaches, or a long freight rake of WAG-9s, is ready in a few clicks for Explore Mode, activities and quick drives.

What you can do

  • Build a consist visually — add, remove and reorder locomotives, coaches and wagons
  • Reads your installed TRAINS\TRAINSET\ folder automatically
  • Saves standard .con files that work in MSTS and Open Rails
  • Edit consists you already use in activities and explore mode
  • Full step-by-step video guide on this page

Requirements

  • Microsoft Train Simulator or Open Rails installed
  • WinRAR or 7-Zip to extract the archive
  • Windows PC — the editor is a native Windows tool

How to use

Five steps. Then the sim loads it.

01

Download

Grab TrainSimConsistBuilder.zip from the file above. 8.61 MB.

02

Extract

Unzip the archive with WinRAR or 7-Zip. Keep the folder as it ships.

03

Point it at MSTS

Open the editor and select your Microsoft Train Simulator folder.

04

Build the consist

Add locos and coaches, arrange the order, and set the counts.

05

Save and drive

Save into TRAINS\CONSISTS\, then select it in MSTS or Open Rails.

Keep a backup of your existing consist files before replacing anything. Tip: keep one master consist per rake — for example WAP-7 + LHB — and copy it for each activity so TRAINS\CONSISTS\ stays tidy.
