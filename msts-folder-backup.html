MSTS.7z.001

First volume. This is the file you extract. Keep it with the other five parts. Do not rename it. 2.10 GB.

Open this part →

Keep all 6 parts in the same folder, then right-click MSTS.7z.001 and choose 7-Zip, Extract Here. The archive cannot be opened with a single part. Windows 10 or 11 is recommended. Open Rails can point at the extracted folder. Leave room for the 11.3 GB download and the extracted folder.

Install

Six steps. Then the folder is live.

01

Download all 6 parts

Save MSTS.7z.001 through MSTS.7z.006 in the same folder. Do not rename them.

02

Install 7-Zip

Use 7-Zip, or a recent WinRAR, so split 7z archives are handled correctly.

03

Extract Part 001

Right-click MSTS.7z.001, then 7-Zip, Extract Here. The other five parts are picked up automatically.

04

Choose the location

Move the extracted folder to a short path such as C:\MSTS or D:\Train Simulator.

05

Check permissions

If files refuse to write, run the game executable as administrator once. Newer Windows may also need the usual compatibility settings.

06

Launch and play

Open MSTS, or add the extracted folder as the content path in Open Rails.

This is a folder backup, not an installer. Back up or rename your existing MSTS folder before you replace anything. Do not overwrite an installation unless you mean to. Extract to a short path without special characters. Long names can break older MSTS utilities.
