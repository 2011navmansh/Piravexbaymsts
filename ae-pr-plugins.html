Install

Four steps. Then it runs.

01

Download and extract

Download the plugin or archive and extract it with WinRAR or 7-Zip if needed.

02

Close the app

Close After Effects or Premiere Pro. Pause anti-virus during install if asked.

03

Copy to Plug-ins

Copy the plugin folder to Adobe After Effects\Support Files\Plug-ins, or run the bundled installer.

04

Restart and use

Restart AE or Premiere. Find the plugin under Effects & Presets and start creating.
